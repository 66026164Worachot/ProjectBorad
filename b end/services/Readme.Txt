db คือ ตัวจัดการข้อมูลพวก database 
ของ supabase จะเป็นคำสั่งพวก sql

oauthMock คือ ตัวล็อกอิน google --อันนี้ไม่ต้องยุ่งก็ได้--

supabase.js คือ ตัวเชื่อมของ supabase ในเว็ป แล้วนำไปใช้ db 
แล้วจะไว้ให้ พวก routes ไปใช้

userService คือ ตัวของจัดการบัญชี user ((ตอนนี้เข้ากับหน้าบัญชี User setting))

menuService คือแสดงรายการอาหาร (ไม่มีจำนวนเพราะแค่แสดงรายการ ตอนนี้ยังไม่ได้ทำบิต)
